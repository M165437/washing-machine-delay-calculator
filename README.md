# Washing Machine Delay Calculator

A small calculator for setting a washing machine's delay timer. Enter the wash cycle duration and your desired finish time, and it shows the delay to set.

- Saves the last entered values in your browser with `localStorage`.
- Provides English and German text based on your browser language.
- Supports light and dark color schemes.

Open `index.html` in a browser. Enter the wash duration and finish time, then select **Calculate delay**.
